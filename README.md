# ЛР 1. Деплой на Render и шаблонизация

## Описание проекта

В рамках лабораторной работы было разработано веб-приложение на основе NestJS, в которое была перенесена клиентская часть (сайт про кошку Нори), созданная ранее.

Приложение развёрнуто на платформе Render и использует шаблонизатор EJS для генерации страниц.

Сайт содержит страницы:
- Главная (Любимое)
- Информация о Нори
- Галерея
- Уход
- Истории
- Контакты
- Отзывы

Реализованы:
- Шаблонизация страниц (header, footer, скрипты)
- Динамические страницы (отзывы, истории)
- Формы обратной связи


## Технологии

- Node.js
- NestJS
- Express
- EJS
- HTML / CSS / JavaScript


## Запуск проекта

### Локально

```bash
npm install
npm run start:dev
```

Приложение будет доступно по адресу:  
[http://localhost:3000](http://localhost:3000)

### Деплой

Приложение развёрнуто на Render.  

Ссылка на сайт:  
[https://m3312-vasilievskaya-backend.onrender.com/gallery](https://m3312-vasilievskaya-backend.onrender.com/gallery)


## Структура проекта

- `views/` — EJS шаблоны страниц  
- `views/partials/` — общие части (header, footer, scripts)  
- `public/` — статические файлы (CSS, JS, изображения)  
- `src/` — серверная часть (NestJS)


## Шаблонизация

В проекте были выделены повторяющиеся части:

- Header (шапка сайта)  
- Footer (подвал)  
- Общие скрипты и стили  
- Навигационное меню  

Страницы собираются с помощью EJS partials.
